# User Data and Account

## Actuarial Exam App

### Delete User Data
Users can delete their data by clicking the in-app button "Delete User Data" that can be found in the Profile screen. Deleting user data will just delete the historical data of a user's attempts. The user's account is kept. 

### Delete User Account
Users can delete their accounts by clicking the in-app button "Delete Account" that can be found in the Profile screen. Deleting the account will delete the account and the user's data.
